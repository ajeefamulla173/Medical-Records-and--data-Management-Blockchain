# Medical Records and Data Management using Blockchain

## Overview
This project presents a secure and decentralized medical document management system built using blockchain and IPFS technologies. The system focuses on ensuring data integrity, privacy, controlled access, and traceability of medical records while placing patients at the center of data ownership.

## Problem Statement
Traditional medical record systems face challenges such as:
- Centralized data storage vulnerabilities
- Unauthorized data access
- Lack of transparency and auditability
- Limited patient control over medical data

This project addresses these challenges using decentralized technologies.

## Proposed Solution
The system leverages blockchain smart contracts and IPFS to securely store, manage, and access medical documents. Blockchain ensures tamper-proof metadata and access control, while IPFS handles decentralized file storage.

## System Architecture
- Blockchain network (Ethereum) for access control and traceability
- IPFS for decentralized medical document storage
- Web and Desktop applications for user interaction

## Applications

### Web Application (React.js)
- Secure login using blockchain wallets
- Role-based access for patients, doctors, and administrators
- Upload, view, and manage medical documents
- Intuitive and responsive user interface

### Desktop Application (Tkinter / CustomTkinter)
- Cross-platform support (Windows, macOS, Linux)
- Username/password authentication
- Automatic opening of documents using native applications
- Same functionality as the web application

## Key Features
- Decentralized medical document storage
- Patient-controlled access permissions
- Tamper-proof record management
- Transparent audit and traceability
- Secure document sharing mechanism

## Technologies Used
- Blockchain: Ethereum
- Smart Contracts: Solidity
- Storage: IPFS
- Web Frontend: React.js
- Desktop Frontend: Tkinter, CustomTkinter
- Languages: Python, JavaScript

## Project Setup Overview
The project uses:
- Hardhat for local blockchain development
- Remix IDE for smart contract deployment
- Docker-based IPFS node for decentralized storage

Detailed setup instructions are provided within the project folders.
